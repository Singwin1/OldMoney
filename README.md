# OldMoney

Minimalistický web pro stylování outfitů v old money stylu — pro muže i ženy. Postavený na pěti kurátorovaných barevných paletách (Hamptons Cream, English Countryside, Burgundy Estate, Yacht Club Navy, Tweed & Oak) a interaktivním outfit styleru, který podle zvolené palety a pohlaví navrhne kompletní look.

## Tech stack

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion (scroll reveal, přechody, mikrointerakce)

## Vývoj

```bash
npm install
npm run dev      # lokální dev server
npm run build    # typecheck + produkční build
npm run lint     # oxlint
```
